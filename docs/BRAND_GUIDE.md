# Brand guide

The new site keeps the existing MSEF color palette. These tokens are documented now and will be implemented in the frontend during Phase 6. See `DESIGN_DIRECTION.md` for typography, layout, responsive, and accessibility guidance.

| Token | Color | Existing use |
| --- | --- | --- |
| Navy blue | `#001F3F` | Primary brand color, headings, dark backgrounds, primary actions |
| Goldenrod | `#DAA520` | Highlight and accent |
| Orange | `#FF8C00` | Secondary accent and calls to action |
| White | `#FFFFFF` | Main background and text on dark surfaces |
| Light gray | `#F5F5F5` | Alternate section background |
| Dark gray | `#333333` | Body text |

Preserve these hues. Later visual work may tune shades for readable text contrast, but should not replace the palette with an unrelated scheme.

The original goldenrod and orange do not meet normal-text contrast on white at their exact listed values. Use them as accents or use a verified darker hue-family shade when a text-bearing surface needs them.
