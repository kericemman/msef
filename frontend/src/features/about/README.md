# About feature

`AboutPage.jsx` composes the public About page in this order:

1. `sections/AboutHeroSection.jsx`
2. `sections/MissionVisionSection.jsx`
3. `sections/PurposeSection.jsx`
4. `sections/ApproachSection.jsx`
5. `sections/DirectorMessageSection.jsx`

Each section keeps its layout and responsive Tailwind styles in its own component file. The Director message uses the copy and attribution supplied for publication and links directly to the provided phone number.
